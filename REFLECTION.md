# Reflection 

## 1. flex-direction: row vs column

Flexbox is a CSS layout system used to arrange elements. flex-direction:row arranges the elements horizontally, from left to right while flex-direction:column arranges the elements vertically, from top to bottom.

## 2. Relative units significance

Fixed pixels remain constant no matter the size of the screen. Meanwhile, relative units changes based on the screen size and other font settings. This is important for responsive design as it allows texts to be able to adjust to different screen size so that they are readable to the reader/user.
