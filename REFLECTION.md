# Reflection 

## 1. HTTP Request Path

When a user enters the URL of my GitHub pages site, the browser first uses DNS to find the IP address associated 
with the domain. Then the browser establishes a connection to the server hosting that site and sends an HTTP
request asking for the website. The server receives the request and sends an HTTP response containing the 
index.html file. After receiving the html file, the browser reads it and looks for any additional resources needed
(links). If there are, the browser sends additional requests for these resources. After all the requests are made 
and responses received, the browser uses these to render and display the website.
